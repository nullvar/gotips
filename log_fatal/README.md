# Go Syslog Example

A simple Go example that demonstrates how to send application logs to the system logger using the `log/syslog` package.

## Description

The program creates a connection to the system syslog service and configures the standard Go `log` package to write messages to syslog.

It uses:

- `syslog.LOG_ALERT` — sets the log severity to **Alert**
- `syslog.LOG_MAIL` — uses the **Mail** syslog facility
- `"Some program"` — identifies messages generated by this application

After configuring the logger, the program calls:

```go
log.Panic(l)
```

This writes the logger object to syslog and then causes a panic.

Because of the panic, the following line will not normally be executed:

```go
fmt.Println("Will you see this?")
```

## Code

```go
package main

import (
    "fmt"
    "log"
    "log/syslog"
)

func main() {
    l, e := syslog.New(
        syslog.LOG_ALERT|syslog.LOG_MAIL,
        "Some program",
    )

    if e != nil {
        log.Fatal(e)
    } else {
        log.SetOutput(l)
    }

    log.Panic(l)

    fmt.Println("Will you see this?")
}
```

## Requirements

- Go installed
- A Unix-like operating system with a syslog service available

Check your Go version:

```bash
go version
```

## Run

```bash
go run main.go
```

The program will terminate with a panic after writing the log message.

## Build

```bash
go build -o syslog-example .
```

Run the compiled binary:

```bash
./syslog-example
```

## Checking the Log

The exact location depends on the operating system and syslog configuration.

On Linux, you can try:

```bash
journalctl
```

or:

```bash
journalctl | grep "Some program"
```

On systems using traditional syslog files, messages may appear in files such as:

```text
/var/log/syslog
/var/log/messages
/var/log/mail.log
```

## Important Note

The `log/syslog` package is deprecated in modern Go versions. It is still available, but new applications should generally use another syslog implementation or communicate with the system logging service through a dedicated library.

Also note that this example intentionally calls `log.Panic()`. Therefore:

```go
fmt.Println("Will you see this?")
```

is unreachable during normal execution because `log.Panic()` logs the message and then calls `panic()`.
